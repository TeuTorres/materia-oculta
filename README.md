# Matéria Oculta — protótipo funcional

Landing page da loja Matéria Oculta (kits de hoodoo prontos para usar).
Projeto acadêmico de identidade visual e experiência digital.

## O que funciona
- Vitrine de kits com filtro por intenção
- Sacola lateral: adicionar, alterar quantidade, remover e subtotal (salva no navegador)
- Menu para celular
- Cadastro no Almanaque com validação de e-mail
- Botão de leituras em "Raízes do hoodoo"

O checkout é simulado: o botão "Finalizar compra" só mostra um aviso.

## Editar
- Nomes, descrições e preços dos kits: array `KITS` no fim do `index.html`.
- Os preços estão como exemplo.
- Lista de leituras: procure por "Espaço para a lista de leituras".
